## 🚀 使用方法

### 1. 构建模板

```bash

npm run build
```

### 2. 构建 CLI

```bash
cd packages/cli
npm run build
```

### 3. 使用洞察功能

```bash
ola
/insight
```

### 4. 导出会话

```bash
ola

```

## ✨ 翻译原则

1. **简洁明了** - 标签文本保持简短
2. **一致性** - 相同概念使用相同译名
3. **友好性** - 使用第二人称"你"拉近距离
4. **专业性** - 技术术语保持准确
5. **可读性** - 避免过长的句子
